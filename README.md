# Api_Gateway

A simple **API Gateway project** built for learning and understanding how an API Gateway works in a distributed application.

## 📌 Project Structure

The project consists of three main parts:

- **Frontend** – Client-side application used to interact with the system.
- **Backend** – Handles the application's core APIs and business logic.
- **Gateway** – Acts as an API Gateway between the frontend and backend services.

## 🎯 Purpose

This project was created primarily for **learning purposes** to understand:

- How an API Gateway works
- Request routing
- Communication between frontend, gateway, and backend
- Basic service separation
- Building a simple distributed application structure
